# เปิดใช้การบันทึกคะแนน

1. เปิด Google Sheets รับคะแนนที่สร้างให้ แล้วเลือก **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจาก [Code.gs](Code.gs) ทั้งหมด กดบันทึก
3. เลือกฟังก์ชัน **setup** ด้านบน แล้วกด **เรียกใช้ (Run)** และอนุญาตการเข้าถึงชีตด้วยบัญชีเจ้าของ
4. เลือก **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
5. เลือกชนิด **เว็บแอป (Web app)** ตั้ง **ดำเนินการในนาม: ฉัน (Execute as: Me)** และ **ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone)** แล้วกด Deploy
6. คัดลอก **URL ของเว็บแอปที่ลงท้าย /exec** ส่งกลับในแชต เพื่อเชื่อมต่อและทดสอบการบันทึกจริง

ไม่ต้องแชร์ชีตคะแนนให้สาธารณะ นักเรียนจะส่งผลผ่านเว็บแอปได้โดยอ่านคะแนนคนอื่นไม่ได้
หากบัญชีโรงเรียนไม่มีตัวเลือก Anyone ให้แจ้งในแชตเพื่อเลือกวิธีที่บัญชีรองรับ

## การทำงาน

- เมื่อทำครบ 10 ข้อ เกมส่งชื่อ ชั้นเรียน คำตอบ และรหัสการส่งผ่าน HTTPS POST
- Apps Script คำนวณคะแนนอีกครั้งและบันทึกเวลาประเทศไทย
- ใช้ lock และรหัสการส่งเพื่อไม่สร้างแถวซ้ำเมื่อกดลองส่งอีกครั้ง
- หน้าเกมแสดงว่าบันทึกสำเร็จเมื่อได้รับการยืนยันเท่านั้น หากเครือข่ายขัดข้องยังดูคะแนนและเข้าบทเรียนได้
- ระบบนี้เป็นแบบทดสอบฝึกเรียนสาธารณะ ไม่ยืนยันตัวตนนักเรียนหรือใช้เป็นข้อสอบที่ป้องกันการทุจริต
