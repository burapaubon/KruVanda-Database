📚 ชนิดและลักษณะของฐานข้อมูล

เป้าหมาย: อธิบาย Field และ Record ได้ เลือกชนิดข้อมูลใน Access 2019 ได้เหมาะสม และออกแบบตารางอย่างมีเหตุผล

1. ฐานข้อมูลคืออะไร?

ฐานข้อมูล (Database — ดา-ตะ-เบส) คือการจัดเก็บข้อมูลที่เกี่ยวข้องกันอย่างเป็นระบบ เพื่อให้ค้นหา เพิ่ม แก้ไข และนำข้อมูลไปใช้ได้สะดวก เช่น ฐานข้อมูลนักเรียน ร้านค้า หรือห้องสมุด

ตาราง (Table — เท-เบิล) เป็นโครงสร้างสำคัญสำหรับเก็บข้อมูลใน Microsoft Access โดยแบ่งเป็นแถวและคอลัมน์

รหัสนักเรียนชื่ออายุวันเกิด
001มานะ1712/05/2009
002มาลี1820/03/2008
003ปิติ1708/08/2009

ตารางตัวอย่างมี 4 ฟิลด์ (คอลัมน์) และ 3 เรคอร์ด (แถวข้อมูล ไม่รวมหัวตาราง)

Field (ฟิลด์)

คอลัมน์หรือคุณลักษณะของข้อมูล เช่น รหัสนักเรียน ชื่อ อายุ วันเกิด

Record (เรค-คอร์ด)

แถวข้อมูลหนึ่งรายการ เช่น ข้อมูลของนักเรียนหนึ่งคน

Primary Key (ไพร-มา-รี คีย์)

ฟิลด์หรือชุดฟิลด์ที่ใช้ระบุแต่ละเรคอร์ดไม่ให้ซ้ำกัน เช่น รหัสนักเรียน

2. ทำไมต้องเลือกชนิดข้อมูล?

Data Type (เด-ตะ ไทป์) เป็นการกำหนดว่าฟิลด์เก็บข้อมูลลักษณะใด ช่วยลดข้อผิดพลาดและรองรับการคำนวณหรือค้นหาที่เหมาะสม

ข้อควรคิด: รหัสนักเรียน 001 แม้ประกอบด้วยตัวเลข แต่ไม่ได้ใช้คำนวณ จึงเหมาะกับ Short Text เพื่อรักษาเลขศูนย์ด้านหน้า

3. ชนิดข้อมูลใน Microsoft Access 2019

รายการต่อไปนี้อ้างอิงชนิด/ตัวช่วยที่พบในเมนู Data Type ของ Access 2019 โดยบางรายการเป็นตัวช่วยสร้าง ไม่ใช่รูปแบบจัดเก็บข้อมูลอิสระ

ชนิดข้อมูล / คำอ่านใช้เก็บอะไรตัวอย่างและข้อควรระวัง

4. แยกให้ออก: ชนิดข้อมูล ≠ รูปแบบการแสดงผล

Number คือชนิดข้อมูลตัวเลข ส่วน Fixed เป็นรูปแบบการแสดงผลตัวเลข เช่น 125.5 อาจแสดงเป็น 125.50 เมื่อกำหนดทศนิยม 2 ตำแหน่ง ไม่ได้เปลี่ยนชนิดข้อมูล

Rich Text เป็นคุณสมบัติรูปแบบข้อความของ Long Text ไม่ใช่ชนิดข้อมูลแยกต่างหาก และ Memo เป็นชื่อเดิมของ Long Text ใน Access รุ่นเก่า

Lookup Wizard เป็นตัวช่วยตั้งค่าการเลือกค่าจากรายการ/ตารางอื่น ไม่ใช่ชนิดข้อมูลสำหรับจัดเก็บแบบอิสระ

5. ตัวอย่างออกแบบตาราง

ชื่อฟิลด์ชนิดข้อมูลเหตุผล
StudentIDShort Textรหัส 001 ไม่ใช้คำนวณและต้องคงเลขศูนย์หน้า
FullNameShort Textชื่อเป็นข้อความสั้น
AgeNumberอายุเป็นจำนวนที่อาจนำไปคำนวณ
BirthDateDate/Timeเก็บวันที่เกิดเพื่อคำนวณช่วงเวลาได้
PaidYes/Noสถานะชำระเงินมีสองค่า
ข้อควรระวัง: ในระบบจริงมักคำนวณอายุจากวันเกิดแทนการเก็บอายุถาวร เพราะอายุเปลี่ยนตามเวลา
ฝึกคิดและลงมือออกแบบ

📝 ใบงานหน่วยที่ 2

สถานการณ์: โรงเรียนต้องการเก็บข้อมูลนักเรียนเพื่อใช้จัดการทะเบียน เลือกชนิดข้อมูลที่เหมาะสมที่สุด แล้วออกแบบตารางของตนเอง

ตอนที่ 1 เลือกชนิดข้อมูล (5 คะแนน)

ตอนที่ 2 ออกแบบตารางนักเรียน (5 คะแนน)

กำหนดชื่อฟิลด์ 5 รายการและชนิดข้อมูลให้เหมาะสม โดยอย่างน้อยต้องมีรหัสนักเรียน ชื่อ วันเกิด และสถานะการชำระเงิน

ชื่อฟิลด์ (Field Name)ชนิดข้อมูล (Data Type)เหตุผลที่เลือก

คะแนนตอนที่ 2 ต้องให้ครูตรวจความเหมาะสมของการออกแบบ ไม่ได้ตรวจอัตโนมัติ เพื่อไม่ให้ระบบให้คะแนนผิดจากคำตอบที่ถูกต้องได้หลายแบบ
