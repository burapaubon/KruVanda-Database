1. ฐานข้อมูลคืออะไร?

ลองนึกถึงร้านเครื่องเขียน ถ้าร้านมีสินค้าหลายชนิด เราต้องจด รหัสสินค้า ชื่อสินค้า ราคา และจำนวนคงเหลือ ไว้ให้ค้นหาและแก้ไขได้ง่าย ข้อมูลที่จัดเก็บอย่างมีระบบเรียกว่า ฐานข้อมูล (Database — ดา-ตะ-เบส)

ตาราง (Table), ฟิลด์ (Field), ระเบียน (Record)

Table (เท-เบิล) คือตารางเก็บข้อมูล • Field (ฟีลด์) คือช่องข้อมูลแต่ละประเภทในแนวคอลัมน์ • Record (เรค-คอร์ด) คือข้อมูลครบหนึ่งรายการในแนวแถว

รหัสสินค้า ← Fieldชื่อสินค้า ← Fieldราคา ← Fieldจำนวน ← Field
0012สมุด25.5010
0013ปากกา12.0020

แถวที่มี “0012 | สมุด | 25.50 | 10” คือ 1 Record เพราะเป็นข้อมูลของสินค้า 1 รายการ ส่วน “ราคา” เป็น 1 Field เพราะเป็นประเภทข้อมูลหนึ่งคอลัมน์

2. ทำไมต้องกำหนดชนิดข้อมูล?

ชนิดข้อมูล (Data Type — เด-ตา ไทป์) เปรียบเหมือนการติดป้ายบนกล่องว่า กล่องนี้เก็บอะไร โปรแกรมจะได้จัดเก็บ ตรวจสอบ และคำนวณข้อมูลได้เหมาะสม

รหัสสินค้า 0012 ใช้ Short Text เพื่อรักษาเลขศูนย์ด้านหน้า • ราคา ใช้ Currency เพื่อเก็บจำนวนเงิน • จำนวนสินค้า ใช้ Number เพราะต้องบวก ลบ และตรวจนับ

ข้อควรระวัง: ข้อมูลที่ดูเหมือนตัวเลขไม่ได้แปลว่าต้องใช้ Number เสมอไป เช่น รหัสสินค้า เบอร์โทรศัพท์ และรหัสไปรษณีย์เป็น “รหัส” ไม่ใช่ปริมาณ

3. รู้จักรายการชนิดข้อมูลใน Access 2019 ทั้ง 14 รายการ

อ่านทีละการ์ด โดยดู ความหมาย → ตัวอย่าง → ใช้เมื่อไร → ข้อควรระวัง รายการบางชนิดเป็นตัวช่วยสร้างหรือชนิดคำนวณ ไม่ใช่รูปแบบเก็บค่าธรรมดาเหมือน Number

หมายเหตุ: รายการที่ปรากฏอาจต่างกันตามรุ่น ภาษา และการตั้งค่าของ Access; Lookup Wizard เป็นตัวช่วยสร้างการค้นหา ไม่ใช่ชนิดเก็บข้อมูลอิสระ และ Rich Text เป็นคุณสมบัติการจัดรูปแบบของ Long Text

5. ทดลองสร้างตารางใน Microsoft Access 2019

ข้อสำคัญ: ภาพต่อไปนี้เป็น แผนภาพจำลองตำแหน่งเมนู ไม่ใช่ภาพหน้าจอจริงของโปรแกรม ปุ่มในเครื่องนักเรียนอาจแสดงเป็นภาษาไทยหรือภาษาอังกฤษต่างกัน

  1. เปิด Microsoft Access 2019 แล้วเลือก Blank database (ฐานข้อมูลเปล่า)
  2. ตั้งชื่อไฟล์ เช่น StationeryShop.accdb แล้วกด Create (สร้าง)
  3. เปิดแท็บ Create (สร้าง) → เลือก Table Design (ออกแบบตาราง)
  4. พิมพ์ชื่อฟิลด์ ProductID แล้วเลือก Data Type เป็น Short Text
  5. แถวต่อไปพิมพ์ ProductName เลือก Short Text
  6. แถวต่อไปพิมพ์ Price เลือก Currency
  7. เพิ่ม Quantity เลือก Number และตั้ง Field Size ให้เหมาะกับจำนวนเต็ม
  8. เลือก ProductID แล้วกด Primary Key (คีย์หลัก) เพื่อกำหนดรหัสไม่ให้ซ้ำ
  9. กด Ctrl+S ตั้งชื่อตาราง Products แล้วเปิด Datasheet View เพื่อกรอกข้อมูล

ครูควรทดลองขั้นตอนบน Access 2019 ที่ห้องเรียนก่อนใช้จริง โดยเฉพาะชื่อเมนูตามภาษาที่ติดตั้ง
