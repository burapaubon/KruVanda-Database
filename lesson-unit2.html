👋 ก่อนเริ่มเรียน

วันนี้เราไม่ต้องจำศัพท์ทั้งหมดในครั้งเดียว เป้าหมายคือ มองข้อมูลแล้วเลือกชนิดให้เหมาะสม พร้อมบอกเหตุผลได้

วิธีเรียน: อ่านทีละส่วน → ดูภาพตัวอย่าง → ลองตอบ → ถ้าตอบผิด ให้กลับมาอ่านใหม่ได้ ไม่ต้องรีบ
① รู้จักตาราง
② รู้จักชนิดข้อมูล
③ ทดลองเลือก
④ สร้างตารางจริง

คำศัพท์สำคัญ: Database (เด-ทะ-เบส) = ฐานข้อมูล, Table (เท-เบิล) = ตาราง, Field (ฟีลด์) = เขตข้อมูล/คอลัมน์, Record (เรค-คอร์ด) = ระเบียน/แถว

2. รู้จักรายการชนิดข้อมูลใน Access 2019 ทั้ง 14 รายการ

แต่ละการ์ดมี คำอ่าน → ความหมาย → ตัวอย่าง → ใช้เมื่อไร → ข้อควรระวัง บางรายการเป็นตัวช่วยสร้างหรือชนิดข้อมูลพิเศษ ไม่ใช่ตัวเลขธรรมดา

หมายเหตุสำคัญ: รายการในเมนูอาจแตกต่างตามรุ่น/การตั้งค่า Access; Lookup Wizard เป็นตัวช่วยสร้าง ไม่ใช่ชนิดจัดเก็บอิสระ; Rich Text เป็นคุณสมบัติการแสดงข้อความของ Long Text ไม่ใช่ชนิดข้อมูลแยก

3. ฝึกคิด: ข้อมูลนี้ควรใช้ชนิดอะไร?

ลองเลือกคำตอบ แล้วกด ตรวจคำตอบ จะมีเหตุผลอธิบายให้ทันที

5. แบบทดสอบหลังเรียน 10 ข้อ

เลือกคำตอบให้ครบแล้วกดส่ง ระบบแสดงคะแนนและเฉลยทันที ไม่มีการส่งชื่อหรือคะแนนขึ้นเซิร์ฟเวอร์ ให้แคปหน้าจอคะแนนส่งครูผ่าน KruVanda Classroom

6. สรุปความรู้ก่อนจบบทเรียน

รหัส ≠ จำนวน

รหัส 0012 ควรเป็น Short Text เพราะ 0 นำหน้ามีความหมาย

ราคา ≠ ข้อความ

ราคาควรเป็น Currency เพื่อใช้คำนวณและจัดการจำนวนเงิน

วันที่ ≠ ข้อความ

วันขายควรเป็น Date/Time เพื่อเรียง กรอง และคำนวณช่วงเวลาได้

📝 ใบงานท้ายคาบ: ออกแบบตาราง Students มีฟิลด์ StudentID, FullName, BirthDate, PhoneNumber, IsActive พร้อมเลือกชนิดข้อมูลและเขียนเหตุผลอย่างน้อย 1 ประโยคต่อฟิลด์ จากนั้นส่งภาพหน้าจอ Design View ใน KruVanda Classroom
เฉลยใบงานสำหรับครูStudentID = Short Text (รหัสอาจมี 0 นำหน้า); FullName = Short Text; BirthDate = Date/Time; PhoneNumber = Short Text (ไม่ใช่ค่าที่ใช้คำนวณ และอาจมี 0 นำหน้า); IsActive = Yes/No (มีเพียงสองสถานะ). หากสถานะมีมากกว่า 2 ค่า ต้องออกแบบฟิลด์ต่างออกไป
